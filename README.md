# Classic_Seer - 某童年游戏的怀旧复刻项目

> 基于 JavaScript + Phaser 3 的某童年游戏的怀旧游戏复刻项目

## 🎮主要功能

### 1. 现在能玩到什么？

####目前已经可以体验到这些内容：
- 新游戏、继续游戏
- 飞船内场景（船长室、实验室、空间站）
- 地图跳转（去不同区域）
- 野外遇敌和回合制战斗
- 捕捉精灵、精灵升级、学技能、进化
- 背包管理、精灵管理、精灵仓库
- 任务系统（接任务、看进度、领奖励）
- 图鉴收集
- 本地存档、导入存档、导出存档

### 2.如何启动？

####在项目目录运行 CMD：

```bash
python -m http.server 8000
```

然后访问：`http://localhost:8000`

## 技术栈

JavaScript + Phaser 3

## 已完成功能（可用）

- ✅游戏主流程：新游戏、继续游戏、主菜单到世界场景切换
- ✅世界探索：飞船场景（船长室/实验室/空间站）+ 星球场景跳转
- ✅地图导航：底栏入口 + 地图弹窗统一跳转
- ✅战斗系统：回合制对战、技能释放、道具使用、换宠、逃跑、捕捉
- ✅成长系统：精灵升级、技能学习、进化流程
- ✅管理系统：物品背包、精灵管理、精灵仓库、图鉴
- ✅任务系统：接取、进度推进、奖励发放
- ✅存档系统：本地自动存档 + JSON 导入导出
- ✅设置系统：音量设置、开发者模式开关

## 项目结构目录

```
Seer/
├─ index.html          # 游戏入口
├─ css/                # 样式文件
├─ assets/             # 图片、音频等资源
├─ data/               # 游戏数据（精灵、技能、物品、任务等）
├─ js/                 # 游戏主逻辑
│  ├─ scenes/          # 各个场景（主菜单、地图、战斗等）
│  ├─ systems/         # 核心系统（战斗、任务、存档等）
│  ├─ ui/              # 弹窗和界面组件
│  ├─ core/            # 核心基础模块
│  └─ utils/           # 通用工具
```
